# To-Do List Web App

A simple and clean to-do list application built using HTML, CSS, and JavaScript. Tasks are saved in the browser's localStorage, so your data stays even after closing the browser.

## Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Data persists using localStorage (no backend required)

## Technologies Used
- HTML
- CSS
- JavaScript

## Live Demo
[Click here to view live demo](https://qamar391.github.io/todo-app/)

## How to Run Locally
1. Clone this repository
2. Open `index.html` in your browser
